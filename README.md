# Farmacia Online

Página web estática de farmacia con catálogo profesional y carrito de compras.

## Cómo usar

Abre el archivo `index.html` en cualquier navegador. Usa `cart.html` para revisar el carrito y finalizar la compra.

Si deseas usar un servidor local, puedes instalar una extensión como Live Server o ejecutar un servidor simple.

## Funcionalidades

- Catálogo de productos con imágenes.
- Carrito de compras totalmente funcional.
- Ajusta la cantidad de cada producto.
- Elimina artículos del carrito.
- Total del carrito actualizado automáticamente.
